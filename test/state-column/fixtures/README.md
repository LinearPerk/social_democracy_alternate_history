# State column fixtures

Game qualities for tests.

- `start1928.json`: a normal-difficulty game at its first page, January 1928.
- `crisis1930.json`, `gov1932.json`: sample states for tests, built by
  overlaying hand-picked values on the 1928 state. They are not reached in
  play. `crisis1930`: October 1930, SPD tolerating a Zentrum chancellor.
  `gov1932`: August 1932, SPD-led Popular Front.
- `*_prev.json`: the same states as they stood at the start of the month,
  for change-feedback tests.
